# BTLO-Barcode-world
CTF
Script del challenge Barcode world

«Barcode World» es un desafío para equipos azules que se ofrece en la plataforma Blue Team Labs Online (BTLO) y en el que los usuarios deben utilizar herramientas como Python, OpenCV y Pyzbar para extraer datos cifrados de imágenes de códigos de barras complejos, que luego se descifran para revelar un mensaje oculto y una bandera. 

Link: https://blueteamlabs.online/home/challenge/barcode-world-3d5303cc46
